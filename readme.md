# Mystery Island – The Lost Lighthouse

## Project Description

A Python text-based adventure game.

The player is stranded on Mystery Island
and must restore the lighthouse beacon
to escape.

## Technologies

- Python
- Git
- GitHub
- unittest

## Game Objectives

- Explore five locations.
- Collect useful objects.
- Solve simple puzzles.
- Manage your energy.
- Restore the lighthouse.
- Escape the island.

## How to Run

python3 main.py

## How to Run Tests

python3 -m unittest discover -s tests -v
